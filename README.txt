ASHWIN K. SESHADRI — PERSONAL WEBSITE
======================================

To deploy this website, place all files in this folder
into the same directory on your web server or hosting folder.

FILES INCLUDED
--------------
  aks.html                    Landing page
  publications.html           Full publications list (filterable)
  group.html                  Research group — current students and alumni
  highlights.html             Research highlights (filterable by theme)
  working_papers.html         Selected working papers
  teaching.html               Teaching (AS 210 and AS 313)
  opportunities.html          Opportunities for prospective students/postdocs
  photo.jpg                   Profile photograph (used on landing page)
  AS210_2026_syllabus.pdf     Syllabus for AS 210 (linked from teaching page)
  AS313_2026.pdf              Syllabus for AS 313 (linked from teaching page)

NOTES
-----
  - All pages share the same sidebar navigation and are interlinked.
  - The site uses Google Fonts (Spectral and Fira Sans), loaded from
    fonts.googleapis.com. An internet connection is required to render
    these correctly; the site falls back to Georgia / system sans-serif
    if offline.
  - No server-side components are required — all files are static HTML.
  - The entry point for visitors is aks.html.
